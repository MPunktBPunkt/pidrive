# Methodik

1. **Scope** — `projects/<slug>/SCOPE.md`
2. **Signale** — `tools/audit_scan.sh` + manuelle Docs; Ergebnis `INVENTORY.md`

4. **Reife** L0–L4 (siehe Template)

Qualität: jede Inventar-Zeile mit Belegpfad; Sheets mindestens L2 für Prioritäts-Technologien.
